    System Architecture & Security Controls

    PhishGuard AI is engineered with strict separation of concerns between the feature extraction pipeline, serialized Scikit-learn inference engine, SQLite persistence layer, and Flask REST API.

    Security Hardening Implemented

    • Zero outbound HTTP requests (SSRF prevention)
    • Regex & length validation on all URL inputs
    • 16KB payload size cap on API endpoints
    • Query-string & credential stripping prior to DB storage

    Planned Roadmap (v2.0)

    • WHOIS domain age & SSL certificate chain inspection
    • SHAP waterfall force plots per individual URL
    • Bulk CSV batch scanner & PDF executive reports
    • Browser extension integration via REST API
